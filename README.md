# 쉿!그널 (아파트 · 층간소음 버전) — 해커톤 프로토타입

> 📦 해커톤 종료 후 보관본 (2026-11-07). 더 이상 운영하지 않는 프로토타입이에요.

층간소음을 얼굴 붉히며 찾아가기 전에, 앱으로 이웃에게 익명으로 정중하게 알리는 서비스.
스터디카페용 [쉿!그널](../quiet-seat)과 같은 이름·로고·구조를 아파트에 맞게 바꾼 버전이다. (폴더 이름은 `knock-neighbor`)

## 주소 구조 (동마다 따로)
| 주소 | 화면 |
|---|---|
| `/` | 소개 + 건물 등록 (층수·라인 수 입력, 관리자 키 발급) |
| `/b/<코드>/` | 주민 앱 (PWA). 세대 QR(`?code=…`)로 들어와 등록 |
| `/b/<코드>/admin` | 관리사무소 화면 |

엘리베이터용 공용 QR은 없다. 등록은 **세대별 QR**로만 한다 (관리사무소 화면 → 세대 QR 탭에서 인쇄).
기본으로 `demo` 건물(행복마을 101동, 10층 × 4라인)이 있다. 관리자 키는 `data/buildings.json`에 있다 (git 제외).

## 주민 기능
1. **세대 등록 (세대 QR)**: 세대마다 다른 QR(등록 코드)을 찍어야 그 호수로 등록된다. 가족은 같은 QR을 찍는다. 시연용으로 관리사무소 설정에서 "호수 직접 입력"을 켤 수 있다 (기본 꺼짐).
2. **소리 민원 보내기**: 윗집·아랫집·옆집 바로가기, 배치도에서 호수 선택, "어디서 나는지 모르겠어요"(위·아래·옆 세대에 확인 요청). 받는 세대에는 보낸 호수가 공개되지 않는다.
   - **기타 (직접 쓰기)**: 100자까지. "다듬어 보기"로 실제 전달될 문장을 확인한 뒤 보낸다.
   - **보내기 제한**: 기기마다 **5분에 1번, 1시간에 최대 3번** (주변 확인 요청·관리사무소 경유도 1번으로 셈).
3. **앱 미가입 세대**: 그래도 보낼 수 있다. "해당 호수는 아직 가입하지 않았어요" 안내와 함께 **관리사무소에 전달**되고, 관리사무소가 연락했다고 처리하면 **보낸 세대에 알림**이 다시 간다.
4. **답장**: 죄송해요 / 곧 끝나요 / 본의 아님 / 저희 집 아니에요 + **직접 쓰기**(100자, AI가 다듬어 전달). 가족 중 한 명이 답하면 모두에게 반영.
5. **신고**: 부당한 알림 신고 → 서로 다른 3세대에게 신고되면 알림 보내기 자동 제한.
6. **미리 양해 구하기**: 종류·날짜(30일 안)·시간(최대 12시간)·한마디(100자). 홈에는 가까운 3개만 보이고, **"캘린더로 자세히 보기"** 를 누르면 월 캘린더로 날짜별 공지를 본다.
7. **관리사무소 문의**: FAQ 카드 챗봇 + 직접 문의 (AI가 다듬어 전달, 원문은 관리사무소만). 답변이 오면 팝업.
8. **🔥 화풀기** (오른쪽 아래): 3D 화풀이 게임 `public/vent.html`. 띄어쓰기마다 단어가 날아가 윗집 캐릭터를 맞히고, 맞을수록 화가 풀린다. **실제로는 아무에게도 보내지 않는다** (게임 안에도 그렇게 표시). 내 윗집 호수가 자동으로 들어간다. three.js(jsDelivr)·Google Fonts를 불러오므로 인터넷이 필요하다.

## 메시지 필터 (AI)
이웃에게 가는 기타 메시지·직접 쓴 답장·양해 공지, 관리사무소 문의는 전달 전에 `llm.js`가 다듬는다.
- 욕설·비하·인신공격을 빼고 정중한 해요체로 바꾸되, 사실(시간, 소리, 빈도, 영향)과 요청은 살린다. 개인정보는 지운다.
- 위협·혐오·괴롭힘만 있는 이웃 메시지·답장은 **전달 차단** (관리사무소 문의는 막지 않고 다듬기만).
- 받는 사람에게는 다듬어진 문장만 간다. **원문은 관리사무소 화면(메시지 필터 탭, 1:1 문의의 "원문 보기")에서만** 볼 수 있다.
- OpenAI Responses API + 구조화 출력(JSON schema). 키가 없거나 호출이 실패하면 기본 규칙 필터(욕설 ○○ 처리, 위협 차단)로 대신한다.

설정 (`.env.example`을 `.env`로 복사, `.env`는 git 제외):
```
OPENAI_API_KEY=sk-...
LLM_MODEL=gpt-6-luna
```
주의: 주민이 쓴 원문이 OpenAI로 전송된다. 실서비스에서는 이용약관·개인정보 처리 동의가 필요하다.

## 관리사무소 기능
- **📺 현황판** (기본 탭): 오늘 소리 민원·답장률·"저희 집 아님"·관리사무소 경유·양해 공지·🍅🥚🍳 화풀기 집계 카드, 동 배치도 위 민원 흐름 화살표(보낸 집 → 받은 집, 방금 온 건 노란 움직이는 화살표), 실시간 소식, 많이 오간 민원·화풀이 표적·많이 던진 세대 순위. 관리사무소 화면의 롱폴링으로 실시간 갱신, 전체 화면 버튼.
- **현황**: 등록 세대, 최근 7일 알림, 반복 소음 세대, 신고, 새 문의 / 소음 지도(층·라인 머리글, 받은 알림 수로 색칠) / 중재가 필요할 수 있는 세대 / 최근 알림 (보낸 세대까지 보임)
- **연락 요청**: 앱 미가입 세대로 온 민원. 메모와 함께 "연락했어요" / "처리 끝" → 보낸 세대에 알림
- **1:1 문의**: 다듬어진 문장으로 보이고 "원문 보기"로 원문 확인. 답변은 푸시로도 전달
- **메시지 필터**: 필터를 거친 글 목록 (전체 / 다듬은 글 / 전달 차단), 원문 보기, AI·규칙 여부
- **공지**: 관리사무소 공지(모든 주민에게 푸시), 주민 공지 내리기
- **세대 QR**: 세대별 등록 QR 인쇄, 이사·분실 시 다시 발급 (예전 QR 무효, 그 세대 주민은 다시 등록)
- **세대 배치 (레고 편집)**: 🧱 세대 놓기 / 🧽 지우기 (누르거나 문지르기) / ✋ 끌어서 옮기기(자리 바꾸기) / ✏️ 호수 고치기. 층·라인 머리글을 누르면 그 자리에 층·라인 넣기·빼기·층 복제. 새 칸의 호수는 위아래 층 번호에 맞춰 자동으로 붙고, 겹치는 호수는 빨갛게 표시된다. 위·아래·옆집은 이 배치를 따른다.
- 신고 처리, 자주 묻는 질문, 건물 이름, 조용한 시간, 시연용 직접 입력 허용

## 실행
```bash
npm install
npm start     # http://localhost:3001 (스터디카페판은 3000), .env가 있으면 읽는다
npm test      # API 흐름 테스트 (임시 폴더 + 가짜 LLM 서버, 실제 키 불필요)
```
- 건물 설정(배치, FAQ, 조용한 시간, 세대 코드)은 `data/buildings.json`에 저장돼 재시작해도 남는다.
- 등록·알림·공지·문의·연락 요청·필터 기록은 메모리에만 있어 재시작하면 초기화된다.
- 보내기 제한은 환경변수 `SEND_GAP_SEC`(기본 300), `SEND_PER_HOUR`(기본 3)로 바꿀 수 있다 (테스트는 풀어서 실행).

## PWA 푸시 · 휴대폰 시연
VAPID 키는 `data/vapid.json`에 자동 생성되고, https(또는 localhost)에서만 푸시가 된다. 아이폰은 홈 화면에 추가한 뒤 열어야 한다.
```bash
cloudflared tunnel --url http://localhost:3001
```
실시간 전달은 롱폴링(`/api/b/<코드>/poll`), 앱이 닫혀 있을 때는 웹 푸시.

## 한계 (프로토타입)
- 세대 QR은 "그 QR을 가진 사람 = 그 세대"로 본다. QR 사진이 유출되면 다시 발급해야 한다. 실제 서비스는 입주민 인증과 연동이 필요하다.
- 세대 QR 주소는 QR을 만든 화면의 주소(또는 `PUBLIC_URL`)를 따른다. 임시 터널 주소로 인쇄하면 터널을 다시 켤 때 못 쓰게 된다.
- 위·아래·옆집은 배치도 칸 기준이라 실제 소리 전달 경로(대각선 등)와 다를 수 있다.
- 조용한 시간은 한국 시간(Asia/Seoul) 기준. 보내기 제한·신고 누적은 기기(브라우저 저장소) 기준이라 저장소를 지우면 우회할 수 있다.

## 화풀기 게임 (`public/vent.html`)
- 띄어쓰기마다 단어가 날아가 윗집 캐릭터에 명중, 기분 게이지가 내려간다. 좌우 드래그로 돌려서 뒤통수도 맞힐 수 있다.
- 🍅 토마토 / 🥚 계란을 골라 캐릭터를 누르면 그 자리로 날아가 얼룩이 3초 남는다 (게이지는 그대로). 합쳐서 10개 맞히면 웍에서 토계볶을 볶는다 (지글지글 햅틱·효과음).
- 맞힌 개수는 앱이 1.5초마다 `POST /api/b/<코드>/vent`로 모아 보내 현황판에 집계된다. 실제 이웃에게는 아무것도 전달되지 않는다.
