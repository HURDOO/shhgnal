# 쉿!그널 정적 데모 (gh-pages)

층간소음을 이웃끼리 정중하게 알리는 앱 **쉿!그널**의 GitHub Pages용 정적 버전이에요.
서버 없이 브라우저 안에서만 돌아가요. 원래 서버 버전(Node + AI 필터 + 웹 푸시)은 `main` 브랜치에 있어요.

## 데모 해 보는 법

1. 첫 화면(`index.html`)에서 **302호**를 새 탭으로 열어요.
2. 윗집 **402호**도 새 탭으로 열어요.
3. 302호 탭에서 윗집에 "쿵쿵 발소리"를 보내면 402호 탭에 바로 알림이 떠요.
4. **관리사무소**(`admin.html`) 탭에서 현황판, 필터 원문, 연락 요청 등을 볼 수 있어요. 데모 관리자 키는 `demo`예요.

탭 하나가 한 집의 휴대폰이에요. 주소의 `?unit=호수`로 세대가 정해져요.

## 어떻게 동작하나요

- `mock-server.js`가 원래 `server.js`의 API를 브라우저 안에서 흉내 내요. 화면 코드의 `fetch('api/b/demo/...')`를 가로채서 처리해요.
- 상태는 `localStorage` 한 곳(`shhgnal-demo-v1`)에 저장해요.
- 같은 브라우저의 다른 탭과는 `BroadcastChannel`로 바로 동기화하고, `Web Locks`로 동시에 고치지 않게 막아요.
- 롱폴링은 "바뀐 게 생길 때까지 최대 25초 기다리기"로 그대로 흉내 내서, 화면 코드는 원래와 거의 같아요.

## 원래 버전과 다른 점

| 기능 | 정적 데모 |
|---|---|
| 다른 기기와 공유 | 안 돼요. 같은 브라우저 탭끼리만 |
| 메시지 필터 | AI 대신 규칙 필터 (거친 표현 몇 개 순화, 욕설 가리기, 위협 차단) |
| 웹 푸시 | 없어요. 열린 탭에서만 알림 |
| 관리자만 원문 보기 | 화면에서만 숨겨요 (데이터는 브라우저에 다 있어요) |
| 건물 등록 | 데모 건물(행복마을 101동, 10층 × 4라인) 하나만 |

5분·1시간 보내기 제한은 그대로예요. 막히면 첫 화면의 **데모 처음부터 다시**를 눌러요.

## 파일

- `index.html`: 데모 안내, 호수 고르기, 초기화
- `app.html`, `app.js`: 주민 화면
- `admin.html`, `admin.js`, `admin.css`: 관리사무소 화면 (현황판 포함)
- `vent.html`: 화풀기 3D 게임 (three.js)
- `mock-server.js`: 브라우저 안 서버
- `sw.js`: 알림 클릭 처리
- `test/static-flow.mjs`: API 흐름 테스트

## 로컬에서 보기 / 테스트

```bash
npm start   # python3 -m http.server 8080 → http://localhost:8080
npm test    # mock-server.js를 Node에서 불러와 API 흐름 97개 검사
```

ES 모듈과 서비스워커를 쓰므로 파일을 직접 열지 말고 http로 띄워서 보세요.
